# GameLetter

[English](README.md)

用 GitHub 维护、自动构建和发布的游戏行业 newsletter / daily brief。

![GameLetter 封面](docs/cover.png)

## 项目包含什么

- 静态发布。
- RSS。
- 自动部署到 Pages。

## 快速开始

安装依赖并启动本地版本：

```bash
npm install
npm run dev
```

仓库还提供 `npm run build`。

## 仓库结构

- `src/` — 应用与库的源代码。
- `scripts/` — 运行时或自动化脚本。
- `docs/` — 项目文档与设计说明。
- `public/` — 公开静态资源。
- `.github` — 自动化与 GitHub Pages 工作流。
